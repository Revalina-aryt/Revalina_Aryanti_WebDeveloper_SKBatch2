# KerjaSpace - Responsive Recruitment Landing Page Section

Landing page rekrutmen responsif yang dibangun untuk menyajikan informasi lowongan kerja, layanan rekrutmen, serta navigasi yang ramah pengguna baik di tampilan desktop maupun perangkat seluler.

## 📌 Fitur Utama
- **Responsive Navigation Header:** Dilengkapi dengan logo, menu navigasi, tombol CTA utama, dan *hamburger menu* interaktif untuk versi mobile.
- **Hero Section:** Headline informatif dengan penawaran nilai (*value proposition*) layanan rekrutmen serta tombol CTA ganda (*Get a Quote* & *Explore Services*).
- **Service & Category Section:** Menampilkan layanan pengembangan karier dan kategori lowongan kerja yang tersedia.
- **Role Cards (Lowongan Kerja):** Kartu informasi lowongan pekerjaan dinamis yang mencakup nama posisi, nama perusahaan, lokasi/metode kerja (WFO, WFH, Hybrid, Remote), serta tipe kontrak.

## 🛠️ Tech Stack
- **HTML5:** Penataan struktur halaman web secara semantik.
- **CSS3:** Styling kustom menggunakan Flexbox/Grid, variabel CSS, media queries untuk preferensi responsif desktop/mobile, serta perbaikan *layout* visual.
- **JavaScript (Vanilla JS):** Mengontrol interaktivitas *hamburger menu* (toggle class active & icon switching) pada navigasi versi mobile.
- **FontAwesome:** Library ikon untuk tombol aksi, panah navigasi, dan hamburger icon.
